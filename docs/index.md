# HeavyTailedNoise: formal proofs for stochastic optimization

HeavyTailedNoise is a Lean 4 library studying the limits of stochastic optimization under moment bounds on gradient noise. Its main release target is the complete lower bound for arbitrary randomized strict-K=1 algorithms: independent fresh samples, gradient-only observations, complete history, arbitrary private randomness, remote queries and arbitrary measurable output.

For `1<p≤2` and every finite `q≥1`, set `A=LΔ/ε²`, `B=(σ/ε)^(p/(p-1))` and `S₊=max(1,σ/ε)`. The complete theorem gives a dimension-uniform response complexity strictly above `c(p,q) max{A+B+AB^(1/q), A S₊²}` under one absolute relative accuracy condition. It includes zero noise and q=1. Its unique canonical package has passed the complete 218-module native build, provenance audit, 18-entry public signature/axiom audit and standalone Full-entry import check.

The gated Haar construction establishes an `A S²` lower term for strict `K=1` access, where `A = L Δ / ε²` and `S = σ / ε`. In the explicit large-parameter regime, the public theorem gives a dimension-uniform minimax response complexity strictly greater than `10⁻²⁵ A S²`, for `1 < p ≤ 2` and every finite `q ≥ 1`. A single publicly selected Haar prior defeats all algorithms at a fixed response budget. The construction uses a smooth objective and independent additive isotropic Gaussian noise.

The library separates reusable analytic and probabilistic tools from individual constructions. Formalization also exposed two invalid intermediate numerical comparisons in the written gated proof; sharper exact estimates preserve its final constants. The separate Fradin v2 Theorem 3.1 branch has a native kernel proof of the three-term rate under its response-only, zero-respecting, shared-seed batch protocol. It includes q=1, zero noise and the small-chain fallback. An explicit first-slot normalization is retained because the source does not define its batched gradient norm. The proof repairs an intermediate support index and uses a documented C² realization. Version 0.2.0 additionally verifies the original strict-K=1 shared-batch EMA upper theorem and its matching-rate corollaries, with explicit constants depending only on p,q and no estimator-error premise in the final statement. The complete 421-module local canonical build, independent upper/matching public import and 30-entry guarded signature/axiom audit passed on 30 September 2026. The same minimax quantity has both lower and upper bounds, with no zero-respecting restriction; the common accuracy condition is A≥10,752,000.

The previous 195-module package passed primary and independent native builds, provenance checks and ten-entry public axiom audits. The published v0.1.0 complete-lower package contains 218 modules and has passed its unified canonical build and provenance check against 223 unchanged frozen inputs. All 18 guarded public audit entries use exactly `propext`, `Classical.choice` and `Quot.sound`; an independent Full-entry import check also passed. A fresh-directory 218-module rebuild has not been performed.
